# 真实美股方法基准

本次运行把 `trader-strategy-lab` 的 M01（科学基线）、M02（中期趋势）和
M12（共同暴露/广度闸门）接入 finance agent 的委员会与质量请求，并用真实
Yahoo public EOD 数据做固定规则对照。运行命令：

```sh
node --import tsx scripts/operator/finance-strategy-method-benchmark.ts \
  --as-of 2026-09-10T23:59:00Z \
  --out .artifacts/finance-strategy/benchmark-20260910.json
```

## 数据和冻结规则

- 标的：SPY、QQQ、IWM、AAPL、MSFT、NVDA；六个标的的共同样本为
  2023-09-11 至 2026-09-09，共 744 个交易日。
- 来源：每个标的均由 `yahoo_public_eod_history` 分三段抓取，三段收据全部
  `ready`；原始字段是未复权 `close`，不含股息。
- 基线：同一篮子买入并持有，入口和退出各计 15bp。
- 方法：前一交易日收盘高于固定 200 日均线，且六标的中至少一半高于各自
  200 日均线，下一交易日才持有；每次切换计 15bp。信号不使用未来收盘。
- 观察窗口按三段不重叠时期报告，不挑选有利时期或参数。

## 组合结果

| 方法            |  总回报 |   CAGR | 年化波动 | 最大回撤 | 换手（单向次数） | 最差单日 |
| --------------- | ------: | -----: | -------: | -------: | ---------------: | -------: |
| 买入并持有      | 111.03% | 28.83% |   20.52% |  -24.21% |             1.00 |   -6.02% |
| 趋势 + 广度闸门 |  26.07% |  8.17% |   13.05% |  -12.42% |            11.67 |   -3.98% |

趋势和广度规则把最大回撤减少约 11.78 个百分点、年化波动减少约 7.47
个百分点，但 CAGR 少约 20.65 个百分点，并没有显示出超越买入持有的收益
优势。第一个三分之一时期因 200 日预热和退出反弹而为 -4.19%，后两个时期
分别为 16.40% 和 13.45%；这暴露了方法的机会成本与反转风险。

## 结论和闸门

这次结果证明的是：提炼材料已进入 agent 的可执行审查上下文，且能在真实
历史数据上产出成本、时点、分段和共同暴露结果。它没有证明模型学会了交易
员策略，也没有证明未来盈利。当前方法保留在 `research_only`；不能晋级为
`paper_candidate` 或任何交易候选，因为三年六标的样本中收益明显落后简单
基线，且使用未复权价格。

下一步若要继续，只能先预注册替代成本、均线区间和更广标的集合，保留所有
结果，再用新的非重叠时期复核；不得根据本次结果反向挑参数。
