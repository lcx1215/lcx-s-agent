# 豆油 Y2501 / 棕榈油 P2501：逐合约研究回放

## 结论

在这一个 DCE 交割月份、这一套固定规则下，价差没有均值回归：4 个入场信号
全部是做多价差，0 次回归，1 次触发止损，3 次持有 20 个交易日后退出。每边
1 手时，毛损失为 ¥10,780；加入明确标注的费用和成交成本情景后，净损失约为
¥11,300 至 ¥11,860。

这不能推出豆油与棕榈油永远不适合相对价值交易。它只说明“收益相关较高，所以
价差会回来”在这组具体合约和规则上没有成立。日收益相关系数约 0.744，但价差
ADF 没有拒绝单位根，AR(1) 系数大于 1，没有有限的常规半衰期。

## 数据和口径

- 研究对象：大商所豆油 Y2501 与棕榈油 P2501，都是 2025 年 1 月交割的具体
  合约；固定价差 `Y2501 - P2501`，每腿 1 手。
- 覆盖：两合约共同交易日为 2024-01-16 至 2025-01-09，共 237 行。P2501
  单独还有 5 个交易日，因 Y2501 数据已结束而未纳入。这里没有拼接主力连续、
  没有跨月，也没有假装这些数据等于可交易的连续策略。
- 数据来源：新浪财经逐合约日线 API，字段为日期、OHLC、成交量、持仓量和结算价；
  原始响应在 2026-09-30 04:31:28 UTC 抓取。CSV 和摘要见 [input.csv](input.csv)
  与 [capture.json](capture.json)。
- 核验：237 个共同日期无重复、OHLC 内部关系异常或零成交量/持仓行。2024-08-26
  新浪收盘价 Y2501=7,566、P2501=8,078，与永辉期货当日数据跟踪表公布值一致。
  早期合约流动性低：首 10 日成交量中位数分别为 Y=172.5 手、P=73.5 手；这些
  数据只作前置历史，首个信号直到 2024-07-12 才出现。
- 官方数据尝试：大商所逐日行情接口在本机请求时返回网站校验页/连接错误；没有
  绕过校验。故这份历史序列仍是供应商数据，经一个独立期货公司报告抽样核对，
  不是逐日交易所对账数据。

合约规格按样本合约时点核对：豆油、棕榈油均为 10 吨/手、人民币元/吨、最小变动
2 元/吨；因此 1:1 手数对应相同吨数，但不代表经济风险完全中性。DCE 棕榈油资料
列出 5% 最低交易保证金；这只是交易所最低基准，不是实际经纪商保证金。来源见
[DCE 棕榈油合约手册](https://www.dce.com.cn/dceg/file/2025-05-29/1748480846087ff80808197162e7116101971994690712d8.pdf)
及标注来源为 DCE 的[豆油合约信息](https://www.ccbfutures.com/en/a/20221210/68504.shtml?catalogno=Soybean_Oil&headercatalogno=rules)。

## 冻结规则与执行近似

研究使用滚动 60 日样本均值和样本标准差计算 z-score，当前日不进入自己的基线；
`|z| >= 2` 入场，回到 0.5 内退出，3.5 止损，最长持有 20 个共同交易日，不重叠，
低于入场阈值后才重新武装。信号在完整日线后产生，按下一共同观察日收盘价成交。
这些阈值是在数据覆盖和基本质量检查后、查看逐笔事件结果前固定的；**没有在取数前
预注册，也没有做参数搜索，因此不能称作事前验证或样本外测试**。

手续费参考 2024-05-06 期货公司公布表中的交易所费率 ¥2.5/手/边；同表的账户公示
标准为 ¥7.5/手/边。所有本次信号发生在 2024-07 以后。表格是经纪商公开费率表，
并非本人的客户账单，也没有逐日核验后续是否调整。回放成本为：

| 情景     | 单边费率 |  每腿完整买卖价差 |     每边滑点 | 4 笔完整价差往返总成本 |   净损益 |
| -------- | -------: | ----------------: | -----------: | ---------------------: | -------: |
| 较低压力 |  ¥2.5/手 |  1 tick = 2 元/吨 |  1 tick/订单 |                   ¥520 | -¥11,300 |
| 较高压力 |  ¥7.5/手 | 2 ticks = 4 元/吨 | 2 ticks/订单 |                 ¥1,080 | -¥11,860 |

一跳/两跳价差宽度和滑点是压力假设，不是历史盘口观察。新浪日线没有买卖报价、
深度、排队、部分成交或两腿先后成交记录。保证金输入用样本最高收盘价乘 10 吨、
乘 5% 的静态最低保证金代理，组合峰值约 ¥9,634；它没有还原交易所/期货公司随
交割临近上调的保证金，也没有假设跨品种保证金抵扣。故净损益区间不是完整的真实
成交成本结算。

## 结果

| 指标                                     |                                    结果 |
| ---------------------------------------- | --------------------------------------: |
| 日收益率相关系数                         |                                   0.744 |
| 收盘价差范围                             |                    -2,370 至 +498 元/吨 |
| 全样本价差均值 / 中位数                  |                        -295 / +82 元/吨 |
| AR(1) 系数                               |                 1.006；常规半衰期未定义 |
| ADF                                      | `unit_root`；统计量 1.452，未拒绝单位根 |
| 信号 / 已平仓 / 回归 / 止损 / 超时       |                       4 / 4 / 0 / 1 / 3 |
| 毛损益 / 较低压力净损益 / 较高压力净损益 |          -¥10,780 / -¥11,300 / -¥11,860 |
| 较低压力下最差观测不利损失               |                         ¥6,730/价差交易 |

四个入场信号都发生在价差为负且继续走弱时。2024-12-30 最后一笔退出时，日成交量
降至 Y=6,064 手、P=16,898 手，低于合约活跃期水平；收盘价近似不能代表该时点两腿
都能按模型成交。这强化了“需要失效退出和容量检查”的方法要求，但不代表其他月份
也会得到同样结果。逐事件输入、方向、日期、损益和退出量见 [result.json](result.json)。

## 复现

在仓库根目录执行：

```sh
node --import tsx docs/experiments/research/commodity-pair-y2501-p2501/replay.mts
```

脚本只读本目录保存的 CSV，调用当前 `quant-math-pair-spread.ts` 诊断和固定价差回放，
然后重写 `result.json`。这证明本地计算核心能消费一组有来源的逐合约数据；它不证明
finance runner/quant_lab 在线路由上真实调用了外部数据源，也不证明模型吸收、Paper、
Live、下单或盈利。
