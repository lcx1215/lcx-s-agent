# Agent Brain Eval

Use the repo owners before making a learning claim:

- `node --import tsx scripts/operator/lcx-context-recovery-exam.ts --json`
- `node --import tsx scripts/operator/local-brain-training-plan.ts --json`
- targeted prerequisite and adjacent-case evals when the plan permits them

Report the evidence path, failed reason, and next owner action. A stored source,
one answer, or one receipt is not `eval_absorbed`. Do not start training, touch
provider/protected memory, or call local replay `user-visible-observed`.
