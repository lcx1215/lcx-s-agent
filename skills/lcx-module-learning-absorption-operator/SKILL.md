# LCX Module Learning Absorption Operator

Read the [runtime contract](../_shared/lcx-runtime-contract.md).

1. Identify the current module, source, application path, decision mode and dated acceptance evidence.
2. Use `node --import tsx scripts/operator/module-learning-pipeline-review.ts --json --no-write` and the relevant `scripts/operator/lcx-module-learning-absorption-gate.ts --json`.
3. Distinguish stored-only, application-ready and eval-absorbed. Verify the capability's actual consumer and an independent or adjacent evaluation; do not promote a status from a document alone.
4. Report a legacy-only or unsupported module/model profile explicitly. Consult training owners only when weight-learning is actually in scope.

No training, corpus/protected-memory write, provider change or external send follows from this audit. Research/strategy candidates retain their mode and evidence boundaries; execution requires its separately authorized shared gate.
