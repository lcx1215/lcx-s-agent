# 策略有效性闸门

这份文件把“方法听起来合理”与“可以进入条件候选”分开。它评估的是研究质量和实施可行性，不保证未来收益，也不改变账户、经纪商或交易权限。

## 四个阶段

| 阶段                          | 可以说什么                             | 必须已有                                                                     | 不能说什么                       |
| ----------------------------- | -------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 'method_only'                 | 来源描述了某种方法，机制值得研究       | 可追溯来源、主张类型、未知项                                                 | 有alpha、现在触发、可复制        |
| 'research_candidate'          | 有明确规则，值得做回测                 | 时点数据、基线、成本模型、无泄漏设计                                         | 已经有效、可以配置资金           |
| 'paper_candidate'             | 在指定样本外区间净成本结果值得继续观察 | 至少三个非重叠时期（数据允许时）、稳健性检查、压力测试、完整决策周期纸面交易 | 适合实盘、已解决容量和融资       |
| 'conditional_trade_candidate' | 在当前数据和约束下满足预设条件的候选   | 新鲜数据、可观测触发、反证、退出、风险预算、流动性和权限检查                 | 自动下单、保证收益、替代用户确认 |

'live_execution' 不在本 Skill 的四阶段闸门内：本 Skill 的最高阶段是 'conditional_trade_candidate'。执行是**独立权限**，只有在显式选择 `live_execution` 模式、指名已声明执行适配器、并且只针对你授权的标的与规模时才会发生；即使研究通过，本 Skill 也不会自行下单。

## 必填证据包

每次从 'research_candidate' 往上走，都要留下：

1. **问题与范围**：策略ID、市场、工具、持有期、基准、研究截止时间。
2. **点时数据**：数据来源、可得时间、修订处理、退市证券、成分变更、币种和时区。
3. **规则版本**：信号公式、参数范围、再平衡、仓位与现金处理；最终参数不能用未来数据挑选。
4. **成本模型**：手续费、买卖价差、滑点、冲击、融资、借券、展期、税费和最小交易单位；未知项用区间和敏感性，不写成零。
5. **基线**：同一市场、同一时间窗口、同一成本口径的简单基线，例如现金、买入持有、等权或固定规则。
6. **验证切分**：训练、验证、样本外和纸面交易区间；滚动前推时记录每次可用信息。
7. **泄漏审计**：收盘信号不能用同一收盘成交；财报和宏观数据使用发布时间；没有未来成分和修订值回填。
8. **稳健性**：参数扰动、替代成本、不同资产/行业、不同市场状态；多次试验要保存而不是只报告胜者。
9. **风险与流动性**：最大回撤、跳空、保证金、借券撤回、退出天数、集中度、共同因子和压力情景。
10. **复盘计划**：触发后何时复查，谁负责记录，什么事实会令论点失效。

## 默认研究门槛

这些是可调整的研究默认值，不是普适收益承诺：

- 研究结果须以**净成本**而非毛收益呈现，并同时报告年化收益、波动、最大回撤、换手、胜率或收益分布、尾部损失和基线差异。
- 结果要跨越至少三个不重叠时期或明确的市场状态；如果历史不足，降级并写明原因。
- 样本外区间必须在最终参数和规则冻结后产生；参数扰动约±20%可作为敏感性起点，但不能用它挑出最好的区间。
- 报告均值之外的区间或重采样结果；单一高夏普、单一危机年份或少数头寸不能晋级。
- 净优势如果只在乐观成本、特定资产或一个时间窗存在，停留在研究阶段。
- 纸面交易至少覆盖一个完整决策周期，并覆盖最坏的可预见执行情景；纸面成交不能假设无限流动性。
- 当前数据缺失、超过该策略所需新鲜度，或无法证明触发时可获得时，禁止输出条件候选。

## 不同策略的最低成本检查

- **M02 趋势**：换手、价差、期货展期、保证金/融资、信号延迟、V形反转。
- **M03 宏观**：首发值与修订值、政策预期、汇率和利率表达的共同暴露。
- **M04 复制**：复制跟踪误差、管理费、再平衡滑点、风格突变和因子估计滞后。
- **M05/M06 股票与反向**：借券费、逼空、停牌、冲击、不利选择和新闻发布时间。
- **M07 折价**：NAV可信度、分配、费用、催化剂成功概率、等待期间收益与折价长期不收敛。
- **M08 信用/可转债**：回收率、条款、融资、保证金、对冲失效、违约跳跃和退出流动性。
- **M09 指数事件**：公告/审核/生效时点、提前抢跑、跟踪资金不确定性和收盘冲击。
- **M10 尾部保护**：期权价差、theta、滚动保费、期限错配、跳空和保护兑现规则。
- **M11 波动率**：完整曲面、gamma/vega/theta、连续对冲成本、相关性跃迁和跳空。
- **M12 组合**：穿透重复持仓、压力相关性、总/净名义、保证金、现金和退出天数。

## 失败与停止

满足以下任一条件时，不升级策略；必要时把现阶段结果降级：

- 数据时点或成交可得性无法证明；
- 成本模型缺失且优势小于合理成本区间；
- 结果依赖单一时期、单一资产、单一参数或事后筛选；
- 回测收益来自未来信息、幸存者样本或未计入停牌/退市；
- 基线更简单、成本相同却表现不差；
- 压力情景超过用户预算，或流动性不足以退出；
- 当前事实与研究假设冲突；
- 来源只能证明“机构这样宣传”，却被写成“方法有效”。

  net_of_costs: true
  leakage_check: "pass"
  robustness: "pass/partial/fail"

  max_drawdown: "数值或区间"
