# 模块研究优先级快照

本表未声明 `as_of`，仅作历史研究规划线索，不代表当前研究成熟度或系统状态。引用任何评分前，先核验对应的最新证据和运行收据；这不是策略晋级闸门，也不是每项任务的必读材料。

证据等级：A = 独立研究加可复现样本外证据；B = 有较强公开研究或机制，但本地尚未完成复现；C = 主要为管理人/从业者自述或规则启发；D = 只有报道、营销或匿名材料。
个人实施：高/中/低表示在普通个人账户中完成合理验证和执行的难度。

## 规划参考顺序

以下顺序是旧的资源规划参考，不要求按序执行，也不要求覆盖全部模块。只有任务需要跨方向盘点时才看[多方向策略研究矩阵](multi-direction-matrix.md)。

1. **M12**：先检查现有持仓的共同因子和流动性，这一步即使没有alpha也能减少错误。
2. **M02**：用透明趋势基线验证策略是否在现实成本下仍有净优势。
3. **M07**：只研究有正式公告或投票/清算路径的折价事件。
4. **M04/M09**：用于解释产品和事件，不把复制或指数调仓自动当成套利。
5. **M03/M05**：等数据时点和资产表达可复现后再进入纸面交易。
6. **M06/M08/M10/M11**：维持研究级，除非获得适合的工具、成本和风险预算证据。

## 评分升级条件

- 证据等级升级需要新的独立来源或可复现结果，不因新增人物案例升级。
- 个人实施等级升级需要通过数据、成本、流动性和权限检查，不因回测毛收益升级。
- 任一策略发生规则、数据或市场结构变化，重新评估；旧分数不自动延续。
