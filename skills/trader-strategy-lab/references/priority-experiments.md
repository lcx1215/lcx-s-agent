# 优先实验协议

这是把方法模块变成可复现研究的第一批协议。它们是 research_candidate 设计，不是当前买卖建议。参数在运行前冻结；如果没有相应的点时数据，保留为方法\_only。

本协议现在服务于[多方向策略研究矩阵](multi-direction-matrix.md)的全覆盖。E01–E03是首批可运行样板，不是研究范围上限；D01–D28均应进入后续队列，并按市场数据、成本和审查容量分批执行。每个方向独立晋级，不能用一个方向的结果替代其他方向。

## E01：M02 中低频趋势

**问题**：趋势信号在现实成本、延迟和不同市场状态下，是否仍优于同市场的简单基线？

**候选规则（运行前全部登记）**：

- B0：同一标的买入持有或现金基线。
- T1：每月最后一个可用时点计算过去12个月总回报；正值持有，非正值持现金；下月第一个可交易时点执行。
- T2：同一信号允许多空，先标为研究级；必须单独计入融资、借券、保证金和跳空。
- T3：跨资产版本按过去波动率做风险归一化，再限制总名义和组合波动；不因为资产数量多就假设独立。

**预注册变化**：同时记录6、9、12、18个月观察窗；不得事后只保留赢家。使用调整后价格和退市/成分历史；信号形成和成交至少错开一个可交易时点。

**成本压力**：至少使用低、中、高三档手续费/价差/滑点；期货另列展期与融资，ETF另列管理费和跟踪误差。报告净收益、换手、最大回撤、压力损失和相对B0差异。

**晋级条件**：冻结参数后，跨至少三个非重叠时期或市场状态，净成本结果在合理成本区间内仍有稳定增量；参数扰动和延迟不会轻易改变结论；纸面交易覆盖完整决策周期。否则降级为研究工具。

**常见误判**：把趋势收益写成每次危机保护；用收盘价同时生成和成交；只测幸存者资产；把双向期货结果直接套到只做多/现金的个人版本。

## E02：M07 封闭式基金折价与催化剂

**问题**：正式催化剂是否足以让折价收敛，且收敛收益能覆盖NAV变化、费用和等待时间？

**候选事件**：要约/回购、清算或重组、董事会/管理协议变化等有原始公告的事件。只有“折价很大”而没有事件路径的标的进入观察表，不进入候选池。

**计算表**：

- 同一估值时点记录价格、NAV、折价、分配、费用、杠杆和币种。
- 记录公告、投票、预计生效、实际生效和撤回日期；所有日期用事件实际可见时点。
- 回报拆成NAV路径、折价路径、分配、费用、交易成本和等待期间替代收益。
- 建立无催化剂匹配组或历史窗口，避免把市场整体反弹当作事件alpha。

**压力测试**：NAV下跌10/20/30%（示例压力，不是预测）、催化剂延迟、失败、比例配售、折价扩大和流动性下降。比例和数值必须在正式研究中登记来源与假设。

**晋级条件**：至少有正式公告、可验证的事件状态和可退出流动性；事件成功概率与净期望收益使用区间而非伪精确点估计；历史样本外收益在保守情景仍有边际优势。没有催化剂或NAV不可核验时停在method_only。

**常见误判**：把折价收窄当成价格一定上涨；忽视NAV下跌；把行动派持仓或媒体传闻当成事件成功保证；忽略个人没有投票和法律影响力。

## E03：M12 共同暴露与融资拥挤

**问题**：多个基金、ETF和股票是否重复承担同一国家、行业、主题、利率、汇率或波动率风险？

**输入**：用户持仓及权重、基金最新可得成分和日期、价格、行业/国家标签、因子映射、保证金/融资与退出天数。基金无法穿透时标为unknown，不把名称当作分散。

**步骤**：

1. 将直接持仓和可穿透的基金成分归并到经济暴露；保留来源日期和穿透比例。
2. 计算名义暴露、穿透暴露、净/总暴露和同一因子重复次数。
3. 在压力场景中上调相关性，至少覆盖科技/AI共同下跌、利率急变、区域股市同步下跌和融资收紧。
4. 输出超过预算的暴露、最短退出路径、可观察的减仓触发和替代方案；不要把相关性估计写成精确事实。

**晋级条件**：不以收益率作为唯一标准；输出能被持仓和来源复核，能识别至少一个可行动的重复风险或数据缺口。数据不新鲜或穿透比例过低时，只输出unknown清单。

**常见误判**：策略名称不同就当作独立；只看净beta不看总杠杆；用历史相关性覆盖压力状态；把一次媒体回撤报道当成稳定择时能力。

## 记录格式

每个实验保存：

- `experiment_id`、规则版本、数据来源和点时日期；
- 预先登记的参数、基线、成本档位和压力情景；
- 全部试验结果，包括失败和被放弃的参数；
- OOS区间、纸面交易观察和未解决风险；
- 当前阶段：method_only / research_candidate / paper_candidate / conditional_trade_candidate；
- 复核日期与降级条件。

没有上述记录，结果只能作为讨论线索，不能晋级。
