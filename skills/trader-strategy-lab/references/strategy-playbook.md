# 可复用投资策略提炼手册

这份手册把三地公开方法转成以后可以重复调用的研究流程。它不是交易员私有算法，也不替代当前数据刷新。

## 从公开材料到策略假说

对每个来源先回答四个问题：

1. 来源明确说了什么方法、工具、期限或风险管理？
2. 哪部分是本研究的推导，能用公开数据反驳？
3. 哪些边界依赖机构专有数据、融资、券源、投票权或执行网络？
4. 发生什么可观察事实时，论点失效或必须退出？

然后形成一条可测试假说：

```yaml
strategy_id: "三地公开方法-版本"
question: "可证伪的问题"
source_fact: "来源原文支持的事实"
inference: "本研究推导的经济机制"
universe: "可交易标的和排除项"
information_cutoff: "数据实际可见时间"
trigger: "可计算、可复核的条件"
baseline: "同市场、同成本的简单基线"
costs: ["费用", "价差/滑点", "融资/借券", "税费或未知区间"]
stress: ["跳空", "相关性跃迁", "融资收紧", "流动性下降"]
invalidation: "可观察反证"
stage: "method_only"
execution_authority: "none"
```

## 三地方法到个人版本的映射

| 公开方法            | 个人可迁移核心               | 先测试什么                    | 常见越界                           |
| ------------------- | ---------------------------- | ----------------------------- | ---------------------------------- |
| 华尔街系统化/多策略 | 预注册、信号去重、风险预算   | 透明基线、样本外和成本        | 把机构收益当作可复制 alpha         |
| 伦敦趋势/宏观       | 跨资产、状态切换、动态减风险 | 趋势与现金基线、利率/汇率压力 | 把宏观叙事写成确定预测             |
| 香港/亚洲股票多空   | 公司治理、催化剂、区域制度   | 公告时点、事件成功/失败、退出 | 把本地网络和股东行动权当作个人可得 |
| 信用/可转债相对价值 | 同一发行人的多证券风险拆分   | 条款、回收率、融资、借券压力  | 把对冲写成无风险套利               |
| 尾部保护/波动率     | 保费换生存、希腊值压力       | 组合层面慢跌/急跌/波动率冲击  | 只看到期 payoff，忽略途中损益      |

## 调用顺序

1. 读取 [有效性闸门](evaluation-gate.md) 和 [当前情报](current-intelligence.md)。
2. 明确研究模式；默认 `research_only`，不自动输出买卖动作。
3. 只有问题确实涉及多个方向时，才读取[多方向策略研究矩阵](multi-direction-matrix.md)并选择相关项；单方向问题直接锁定该方向的市场、期限、标的、分母、数据时点和基线。
4. 先用真实公开数据做最小测试；数据缺口进入 `unknown`/`gate_status`，不填代理值。
5. 运行成本、压力、泄漏和流动性检查，再决定保留、降级或停止。
6. 只有经过样本外和完整纸面周期，才可能进入 `paper_candidate`；条件候选仍需人工确认，执行权限永远为 `none`。

## 未来输出格式

每次输出按以下顺序：来源事实 → 当前数据 → 规则与基线 → 净成本结果 → 压力与失效 → 候选/观望 → 未知项 → 复核日期。新闻只作为触发候选的输入，不能单独构成买入理由。

## AI/科技时代研究模板（2023—2026）

研究AI主题或机器学习量化时，先把对象分为四层：

1. **技术/产业基本面**：模型能力、客户采用、收入与毛利、资本开支、折旧、供应链和监管；不能只用“AI”标签。
2. **信号层**：价格、财报、公告、另类数据、文本或模型预测；记录信息实际可见时间、目标定义、训练/OOS切分和与已有信号的相关性。
3. **决策层**：AI生成的候选必须由人工复核、来源交叉验证和风险预算过滤；Coatue公开材料明确AI支持研究而非替代投资人员。
4. **执行/组合层**：分别测滑点、借券、融资、库存、容量、流动性和共同AI基础设施暴露；XTX/High-Flyer式机构优势不能直接移植。

匿名模型或AI辅助散户材料只可作为信号发现/负面样本。任何排行榜、质押分数、聊天回答、社交情绪或媒体收益都要经过独立点时、简单基线、净成本、压力和漂移测试；无法映射到可交易标的或缺少完整记录时，阶段保持 `method_only`。

AI主题的最小验证包应输出：技术/现金流假说、可见时点、同主题重复暴露、估值与资本开支敏感性、模型漂移、融资/借券压力、反证和停止条件。没有这些字段，不输出资产级买卖动作。
