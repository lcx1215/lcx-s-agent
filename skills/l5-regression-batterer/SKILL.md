# L5 Regression Batterer

Use this after a shared routing/doctrine/status change or on an explicit request
for the local L5 battery.

## Workflow

1. Resolve the current repo and run the read-only local-brain training plan
   owner; use its process/eval status instead of a duplicate manual scan.
2. Resolve this Skill's directory from the loaded Skill and inspect the shipped
   wrapper and its supported mode before invocation (`--local` in the current
   wrapper). Do not rely on a personal absolute path.
3. Keep tests local and bounded; classify failures by family instead of adding
   phrase-specific patches.
4. Record command, commit, pass/fail counts, and the next owner action.

## Boundaries

- The current wrapper covers selected routing, doctrine, context-recovery, and
  status-boundary checks; it is not a finance-strategy backtest.
- This battery does not prove external-message visibility, provider quality,
  or model-weight absorption.
- Never launch it concurrently with a guard, teacher, MLX eval, or heavy
  training process.
